Key observations from this order
1
Lines 10–70 show delivery created (LFSTA = C on Sales Order) but PGI has not been posted (WBSTA = A on Delivery 8212857277) — goods have not physically left the warehouse despite the Sales Order showing these lines as "Completed."
2
Line 80 has no delivery created and is not yet confirmed — this single line is holding the entire header at "Partially Delivered." It should be flagged visually as the blocking item.
3
Lines 90 and 100 are on Delivery 8212858324 — PGI has been posted (WBSTA = C) and billing is complete (FKSTA = C). These are the only lines that are truly complete end-to-end.
4
SAP header status alone ("Partially Delivered / Partially Invoiced") does not tell users which lines are blocked, which have shipped, or which have been invoiced. The per-line widget is essential for meaningful order visibility.
5
Dev must query VBUP for the Sales Order document (LFSTA) AND separately for each Delivery document (WBSTA, FKSTA) — these are separate records in VBUP and cannot be retrieved in a single document query.
